# Learn Dashboard Design with Phoebe

Six 45-minute sessions on designing a dashboard that answers a question someone has on a schedule:
who looks and what they decide, hierarchy and the first glance, density and grouping, colour as the
state of a KPI card, interaction and a five-user test, and a red-amber-green bench where the
thresholds you set are scored on 581 real days of orders and deliveries, in the browser.

- Open `index.html`, or the published site once it is live.
- `courses/` holds the six session pages; `assets/dsh-live.js` is the bench engine and
  `assets/dsh-daily.js` the derived daily series (Brazilian E-Commerce Public Dataset by Olist, Kaggle,
  CC BY-NC-SA 4.0; daily aggregates only, no rows).
- `materials/` holds the source map, the data builder, the Python reference that must agree with the
  browser engine, and the fan-out brief.

The running case, Saltmarsh, is constructed. By Phoebe Fu.
